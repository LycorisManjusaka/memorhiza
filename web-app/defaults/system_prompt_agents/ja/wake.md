# 起床の [MEMORHIZA] 通知（謡_14 の下書きを初版としたもの）

この線より上だけが、起床したターンで存在に送られます。毎回ディスクから読み直すので、書き換えれば次の起床から効きます。

差し込み口（Memorhiza が埋める）：
- `{SHORT}` … 履歴に残る1行と同じ文（「定刻（04:00）になったため、自律ターンが開始されました。」）
- `{PREVIOUS}` … 前回の自己予約が条件に合わず登録されなかったときだけ、その事実の1行。無ければ空。
- `{CAPABILITIES}` … 起きる会話の設定で ON になっている道具だけのリスト＋最後に必ず「何もしないで終えてもいい」の1行。
- `{SELF_WAKE}` … 自己予約が許可されているときだけ、`[->wakeup: HH:MM]` の書き方と管理者の条件（数字入り）。無ければ空。

履歴（ディスク）に残るのは {SHORT} の1行だけです。この全文は、そのメッセージが最後の USER ターンである間だけ存在に届きます。
